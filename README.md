# HR Dataset Analytical Dashboard
## Project Overview
This project delivers an interactive executive dashboard built in Microsoft Excel to track job roles, monthly revenue, total overtime, Number of employees, department category, for a simulated HR analytics.
An interactive excel dashboard analyzing HR Dataset, KPI metrics, Income categories and monthly data

## Key Features & Technical Skills Demonstrated

Advanced Formulas & Functions:* Utilized XLOOKUP, VLOOKUP, SUMIFS, and dynamic array formulas.
Data Modeling & Preparation: Built relational data models, cleaned raw data using Power Query, and handled error-checking.
Interactivity: Integrated slicers, timeline filters, and KPI summary cards for dynamic user filtering.
* *Design & UX: Applied professional color theory, clear visual hierarchy, and a clean grid layout tailored for executive presentations.
